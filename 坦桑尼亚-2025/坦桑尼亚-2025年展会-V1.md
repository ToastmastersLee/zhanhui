# 二、 展会部署详细信息



## 2.1 基础建设区

<img src="./img/image-20250515174150396.png" alt="image-20250515174150396" style="zoom: 50%;" /> 



- **一、设备清单**
  1. Web-console Server ×1
  2. Lite Media Server ×1
  3. Router ×1
  4. Network Switch ×1（建议12口以上 PoE交换机）

- **二、线材清单（按类型 + 粗略长度估算）**

  | No.  | 类型                  | 用途                                  | 长度估算 | 数量建议 |
  | ---- | --------------------- | ------------------------------------- | -------- | -------- |
  | 1    | LAN网线（Cat6或以上） | Server ↔ Router<br />Router↔ Switcher | 3米 / 根 | 3根      |
  | 2    | LAN网线（Cat6或以上） | Switcher ↔ NDP100                     |          |          |
  | 3    | LAN网线（Cat6或以上） | Switcher ↔ NDP500                     |          |          |
  | 4    | LAN网线（Cat6或以上） | Switcher ↔ NSP                        | 15米     |          |

- **三、 排插/供电需求（Power Strip）**

  | 区域              | 建议插孔数    | 说明                                                |
  | ----------------- | ------------- | --------------------------------------------------- |
  | Router + Switch区 | 4~6 孔插排 ×1 | 交换机、路由器，长度1.5~3米                         |
  | 服务器区（x2）    | 6孔插排 ×1    | Web-console Server + Lite Media Server，长度1.5~3米 |
  | 备份/调试区       | 4孔插排 ×1    | 备用笔电、调试器材，长度1.5~3米                     |
