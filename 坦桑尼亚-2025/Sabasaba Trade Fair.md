# Sabasaba Trade Fair

[toc]

###  什么是 Sabasaba？

- **Sabasaba** 是斯瓦希里语，意思是 "**七七**"，即 **7月7日**。
- 它是坦桑尼亚的 **“国际贸易博览会”**（**Dar es Salaam International Trade Fair, DITF**）的举办日。
- 每年 7 月 7 日，坦桑尼亚在 **达累斯萨拉姆（Dar es Salaam）** 举办这个大型展会。
- 展会主要由 **Tanzania Trade Development Authority（TanTrade）** 主办。



### Sabasaba 展会特色：

| 项目     | 内容                                              |
| -------- | ------------------------------------------------- |
| 举办城市 | 达累斯萨拉姆（Dar es Salaam）                     |
| 举办日期 | 每年 7 月 7 日左右                                |
| 举办地点 | Mwl. Nyerere Trade Fair Grounds（尼雷尔展览中心） |
| 展会性质 | 国家级国际贸易展，吸引非洲和全球厂商参与          |
| 主要目的 | 商品展示、技术推广、跨国合作、政府对接等          |



## 一、Sabasaba 的由来

“Sabasaba” 是斯瓦希里语 **“七七”** 的意思，对应 **7月7日**。

### 📜 起源背景：

- **历史上**，坦桑尼亚的执政党 **坦桑尼亚革命党（Chama Cha Mapinduzi，CCM）** 的前身是 **非洲国家联盟（TANU）**。
- 1954年7月7日，**朱利叶斯·尼雷尔（Julius Nyerere）** 领导成立了 TANU，该组织后来在坦桑尼亚争取独立过程中起到了核心作用。
- 为纪念这一政治转折点，**7月7日被定为国家纪念日**，称为 **Sabasaba Day**，意味着“革命日”或“独立运动的起点”。

------

## 🏢 二、Sabasaba Trade Fair（DITF）的发展

### 📌 全称：

**Dar es Salaam International Trade Fair**
 （达累斯萨拉姆国际贸易博览会）

### 🗓 起始时间：

- 起始于 **1963年**，并从1976年开始由 **TanTrade** 正式运营。

### 📍 举办地点：

- **尼雷尔国际展览中心**（Mwl. J.K. Nyerere Trade Fair Grounds）

### 🎯 展会目的：

| 目标                 | 说明                                                    |
| -------------------- | ------------------------------------------------------- |
| 推动本地产业与出口   | 鼓励本地制造商与国际买家建立联系                        |
| 加强东非地区经济合作 | 吸引来自肯尼亚、乌干达、卢旺达、赞比亚等国家的参展商    |
| 展示技术创新与新产品 | 提供新品发布与演示平台，尤其是农业、ICT、教育设备等领域 |
| 对接政府与商业资源   | 多部门协作，提供项目落地政策支持                        |



------

## 🌐 三、国际影响力

- 被称为 **东非地区最具影响力的贸易平台**。
- 吸引来自 **40多个国家** 的参展商，包括中国、印度、土耳其、德国等。
- 展览内容涵盖 **农业机械、食品、建材、家电、教育产品、ICT、汽车配件等**。

------

## ✍ 总结一句话：

> **Sabasaba** 既是坦桑尼亚政治历史的纪念日，也是国家对外经济窗口的重要象征。每年7月7日前后举办的 **DITF** 不仅是坦桑尼亚最大的贸易博览会，也是在非洲大陆极具战略意义的国际展会。





## 斯瓦希里语（Swahili）

- **Swahili**（斯瓦希里语）又称 **Kiswahili**，是**非洲最广泛使用的语言之一**。
- 属于 **班图语族（Bantu languages）**，但同时也受到 **阿拉伯语** 深远影响（因为历史上的阿拉伯商人和伊斯兰文化传播）。
- 是一种 **混合语言（creolized language）**，融合了非洲本土语言 + 阿拉伯语 + 波斯语 + 葡萄牙语 + 英语词汇等。

------

目前估计有超过 **1亿人** 能够理解或使用斯瓦希里语。

### 👥 “斯瓦希里人” 是什么人？

- **斯瓦希里人（Swahili people）** 是生活在 **东非沿海地区**（主要是肯尼亚、坦桑尼亚沿海及桑给巴尔）的一个**民族和文化群体**。
- 他们是非洲本地人与阿拉伯移民长期通婚和交流的后代。
- 斯瓦希里人多数信奉 **伊斯兰教**，文化上深受阿拉伯影响（比如服饰、饮食、建筑风格）。
- 所说的语言就是 **斯瓦希里语（Kiswahili）**，但如今这个语言早已突破民族界限，成为一种 **泛东非的官方与通用语言**。

------

### ✅ 总结一句话：

> **斯瓦希里语** 最初确实是**斯瓦希里人**的语言，但今天它早已成为东非多个国家的官方语言与跨族群通用语，不再只属于某一个民族，而是整个东非地区文化和沟通的桥梁。
