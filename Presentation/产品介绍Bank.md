## 概述

**单台：**

NDP500是一款高度集成的智能桌面讲台，面相国际教育市场，提供教育装备的集中控制和远程管理的功能。

单台的NDP500集成多种接口，可以提供对多媒体音视频的切换和管理功能，如可以实现多个输入输出源的切换，允许接入音响并对这些音响；另外也可以对教室内的空调，电视、IPF等设备实现本地(NDP500 Touch Panel)和远程（Web-Cosnole, Q-NEX APP）的控制。因此NDP500可以实现，一台设备就可以实现一个智慧教室解决方案。而对于礼堂，Lecture Hall这类面积很大的教室，



**Horizontal Integration：**

以及结合公司现有周边系列产品（如IFP, Wirless Presentation, 录播产品，Media Sever，音频系统等），构建出一整套智慧教室解决方案，对于大面积的场地，可以搭配CBX(Control Box)，通过2.4G Wi-Fi实现远距离无线控制，可以构建智慧礼堂解决方案。



**Vertical Integration：**

NDP500还可以与IQ锐达公司其他类型的集控设备（NDP100， NMP211)统一管理和协同工作， 多个NDP设备通过纵向集成，构建了全校数字化生态系统, 形成全校园解决方案，如智慧校园，Campus-Wide 广播解决方案 。



## Live-streaming

1. **Server Setup**
   The live streaming feature works similarly to the broadcasting feature, meaning it needs an additional server provided by the school. However, if the school already has a server set up for broadcasting, that same server can be used for live streaming as well—no need to buy another one.
2. **Create a New Live Room**
   On the live streaming control page, you can create a new "Live Room." This room will generate a streaming address and a stream key, which you’ll provide to your video source device (like a smartphone, IP camera, etc.).
3. **Configure the Stream Key and Address**
   After generating the streaming address and stream key in the live room, you’ll need to provide these details to your video source device. Once configured, the video source will start pushing the video stream to the live room.
4. **Preview Video Content**
   The live room will show a real-time preview of the video content being pushed by the video source device. This lets you check and ensure the video quality is up to standard before going live.
5. **Select the Streaming Devices**
   After previewing and confirming the video content, you can select one or more devices (like NMP, NDP, MBX, etc.) to receive the live stream. These devices have the capability to decode the stream and display it on connected screens (like IPF, TVs, etc.).

### What is an Active Capacitive Pen?

An active capacitive pen, also known as an active stylus, is a special type of pen used with touchscreens, like those on tablets or interactive whiteboards. Here’s what makes it special:

1. **Electronic Components**: Unlike regular styluses, an active capacitive pen has electronic components inside. These help it communicate more effectively with the screen.
2. **More Precise**: It can draw more precise lines and make writing or drawing on the screen smoother, just like using a real pen on paper.
3. **Extra Features**: Many active pens can sense how hard you’re pressing and can even detect the angle you’re holding the pen. This can make drawing more realistic.
4. **Better for Certain Tasks**: Because it's more precise, it's great for tasks that require accuracy, like writing notes, drawing, or navigating complex interfaces.
