# 迪拜展位空间实验室 — Three.js POC

本地运行的 3D 展位布局工具。外轮廓 5,000 × 5,000 mm，墙高 4,000 mm，墙厚 200 mm。所有业务数据使用毫米，Three.js 渲染时转成米。

接手项目请先读 [交接手册](./交接手册.md)：包含当前场景与资料入口、成熟产品和新品两路参数来源、接线与 OPS 部署填写表，以及多展会复用方向。每届展会只维护当前有效方案，过程记录继续放在项目 Markdown／Excel 中。

**当前导出存在版本标记问题**：按钮输出 `version: 1`，但包含新版19件物件，直接回导会被旧版数量校验拒绝。正式方案归档前需优先修复并验证真实导出往返，详见交接手册“保存现状与已知问题”。

## 启动

Windows 可直接双击 [启动.bat](./启动.bat)：后台启动本项目并打开浏览器；双击 [关闭.bat](./关闭.bat) 停止该服务。重复启动会复用已有服务。首次使用仍需安装 Node.js 并在本目录运行 `npm install`。脚本使用固定端口 5173，进程记录及日志位于 `.runtime/`，由 [本地服务脚本](./scripts/local-server.ps1) 管理；端口被其他方式启动的服务占用时会提示，不会强制关闭其他进程。

需要 Node.js 20.19+ 或 22.12+。

```powershell
cd D:\Github\IQ\zhanhui\booth-poc
npm install
npm run dev
```

打开终端打印的本地网址。`npm run build` 输出静态网页到 `dist/`，可部署到普通静态服务器；不要直接双击 index.html。依赖随构建打包，运行不依赖在线 CDN。

## 操作

- 拖动空白处旋转，滚轮缩放，右键拖动平移。提供正视、俯视、左右墙立面。
- 点击物件或左侧清单选中，拖动彩色坐标轴调整位置。壁挂物件沿所属墙面移动，柜体和讲台沿地面移动。
- 属性面板输入精确毫米数，调整尺寸、离地高度、沿墙位置。50 mm 吸附仅影响鼠标拖动。
- 下沿离地和上沿离地自动更新；简化包围盒检查物件重叠。位置限制在展位范围内。
- 自动保存至当前浏览器 localStorage；提供 JSON 导入/导出入口，当前导出回导问题见上方说明。撤销 / 重做保留本次会话最近 60 步。
- 勾选透视墙体，自动淡化靠近观察者的墙体，便于从外部查看内部物件。

## 验证与范围

`npm test` 检查边界约束、离地高度、重叠识别和 JSON 校验；`npm run build` 验证打包。

本版验证真实 WebGL 渲染、可交互场景和参数化布局，不包含结构承重、安装孔位、支架、多人实时协作或 CAD 施工图。包围盒重叠检测是讨论辅助，不代表完整施工校核。每个物件的来源说明用于区分图纸尺寸与暂估参数。

核心文件：`src/layout.js` 为参数及约束，`src/main.js` 为 Three.js 场景和编辑交互，`src/style.css` 为界面。

## POC 02：检修口与走线

新增三处实际开口：宽 1,000 × 高 250 mm、下沿离地 350 mm（示意尺寸，待核对）。左侧清单可选检修口，输入沿墙位置、宽高、下沿高度；点击“调整开口高度”后，拖动开口顶部绿色轴，保持下沿不动。

左右柜顶各增加一台笔记本，台面内可移动，随柜体跟随；左右柜内各一只排插，后墙检修口下方一只排插。排插自动定位。设备接口为示意占位。

走线模式默认打开。橙色电源、蓝色 HDMI、紫色 USB，分类可隐藏。选四块主 IFP 或检修口、笔记本、柜体、讲台可突出关联路线并在属性面板查看连接名称。虚线表示墙内、地板下、柜内隐藏段；物件移动后路线自动更新。

- 左右 IFP：各一根电源接柜内排插，HDMI / USB 穿检修口后从柜后上引至笔记本。
- 后墙两块 IFP：两根电源接后墙排插；HDMI × 2、USB × 2 穿地板至讲台。
- 地板下深度 30 mm 仅用于示意层次，不是开槽或地台结构规格。总共十二根线；不计算线缆采购长度、电气性能或施工要求。

内部数据和浏览器自动保存使用 version 2；导出包含新增物件、笔记本相对台面坐标和连接关系，但导出按钮的版本标记仍为 version 1，尚待修复。正确的旧版 11 件物件 version 1 JSON 可导入并补齐默认检修口和附属设备。导入器目前仍使用固定连接关系，尚未采用文件中的连接表和展位尺寸。新增编辑支持自动保存、撤销、重做与恢复初始布局。
