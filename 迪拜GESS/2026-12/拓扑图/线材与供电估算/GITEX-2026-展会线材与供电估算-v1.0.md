# GITEX GLOBAL Dubai 2026｜展会线材与供电估算 v1.0

[toc]

<img src=".\img\image-20260819153059412.png" alt="image-20260819153059412" style="zoom: 67%;" />

> 依据当前拓扑 UI 的初步估算，供团队测长和讨论使用。长度列均留空，待现场布局确认后填写；本文件不是施工或采购冻结清单。

- 蓝：LAN；红：HDMI；黄：USB；绿：音频；黑色虚线：无线关系，不计实体线材。
- 黑色插头：设备需要 AC 供电，不是信号线。
- 供电结构：`区域地插 → 1–3 只经搭建方认可的 2–10 位 PDU/排插 → 本区设备`。
- 搭建商：**杭州励创**（特装搭建商；对接群：《锐达互动&杭州励创 -2026迪拜gitex搭建》；对接人：CC、冰雯）。
- 取电点、回路、容量、插头和分支方式由**冰雯、技术团队与杭州励创**确认。
- 展会数据： 5 x 5 x 2.8 （m）；2026-10-19 杭州励创最新效果图确认展位**左右两侧各设有一个柜子**，为基础设施放置与穿线暗埋提供物理收纳。
- **穿线与开孔施工规范（2026-10-19 杭州励创标准）**：
  - 墙体上方挂屏处开 80×80mm 方形过线孔；
  - 墙体下方及柜体背板对齐开 150×150mm 方形穿线孔（或背景板留长开槽）；
  - 弱电 LAN 网线、强电电源线及 HDMI 线从墙内暗埋垂直下落，由背孔引入柜内；
  - 柜内设置带锁柜门，内部放置 3 组多位排插，收纳交换机、路由器及集中走线。
