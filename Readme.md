## 2. 展会相关的单词

> https://chatgpt.com/c/68492313-d71c-8012-b962-1e07d999cc61

| 词语           | 中文常见翻译       | 适用场景与含义                                               |
| -------------- | ------------------ | ------------------------------------------------------------ |
| **Trade Show** | 行业展会、商业展览 | 通常指**专业观众**参与的行业级展会（如Infocomm、CES等）      |
| **Expo**       | 博览会             | **大型综合展览**，通常面向公众或多个行业，如World Expo（世博会） |
| **Fair**       | 展销会、博览会     | 偏重**销售与推广**，可能更本地化或面向普通消费者             |
| **Exhibition** | 展览               | 偏重“展示”本身，可用于艺术展、科技展，也可用于行业产品展示   |

所以 Infocomm 应该叫：

> **Infocomm Trade Show** 或  **Infocomm Expo**

因为它是一个面向**AV 和 IT 行业专业人士**的**技术类商业展览会**，强调新品发布、渠道对接和专业技术交流。

## 3. 出差报告

出差报告不要大篇幅的讲展位装修. 装修细节改进的问题可以单列出来给冰雯. 报告重点在

1. 客户到访情况. 
2. 客户反馈的市场动向,订单/项目相关.
3. 产品演示遇到的问题.客户提出的产品需求. 
4. 现场有听到或者看到的同行动向.
