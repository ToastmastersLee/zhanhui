# Lumens全套 Dante 音视频会议解决方案分析

[toc]

<img src="./img/image-20250731101439639.png" alt="image-20250731101439639" style="zoom:50%;" /> 

> Lumens 这套基于 Dante AV-H 构建的 OIP-N 会议系统，代表了未来会议室/教室系统的 IP 化、可视化方向。对于想要减少布线成本、提高部署灵活性、提升系统兼容性的用户来说，是非常值得参考的解决方案。

 

这套方案基于 Lumens 的 OIP 系列设备（OIP-N40E 和 OIP-N60D）+ Dante 网络系统，构建出“纯IP化”的会议室部署方式。

## 核心设备

| 设备                  | 型号                                | 说明                                                         |
| --------------------- | ----------------------------------- | ------------------------------------------------------------ |
| 摄像头                | **VC-TR60A Dante AV-H**             | 支持 Dante AV-H 的自动追踪摄像头（带USB/IP双输出）           |
| 吸顶麦克风            |                                     | 通过 Dante 网络与音频处理系统连接                            |
| 吸顶喇叭              | Dante Loudspeaker                   | 接收 Dante 网络音频直接播放                                  |
| OIP Bridge（Decoder） | **OIP-N60D Dante AV-H**             | 将 IP 摄像头的视频信号解码成 HDMI 输出                       |
| OIP Bridge（Encoder） | **OIP-N40E Dante Ready**            | 将本地 USB-C 设备（如笔电）信号编码传入 Dante 网络（含音视频） |
| 终端系统              | 会议平台 Zoom / Teams / Google Meet | 通过 USB-C 与编码器连接，可发送本地画面 + 接收远端音频       |

 

## 方案逻辑

<img src="./img/image-20250731101402290.png" alt="image-20250731101402290" style="zoom: 80%;" /> 

```css
[教师/发言人] ← 追踪摄像头（Dante AV-H）
       ↓
    IP 网络（CAT6） ←→ OIP Bridge 解码 → HDMI 显示画面

[学生发言/拾音] → Dante 吸顶麦（RJ45）
[声音播放]       ← Dante 吸顶喇叭（RJ45）

[笔记本电脑] → USB-C 接入 OIP-N40E → 编码至 Dante 网络
```

所有设备都通过标准 **CAT6 网线** 接入同一局域网（LAN），利用 **Dante AV-H（视频）+ Dante Audio** 传输，达到：

- 无需HDMI / XLR等传统布线
- 一网多用（音频、视频、控制信号全IP）
- 软硬件高度解耦，部署自由度高



## 方案亮点

| 类别      | 特点                                                       |
| --------- | ---------------------------------------------------------- |
| 全Dante化 | 音频+视频均通过 Dante 网络传输，无需传统音视频分线         |
| 解耦设计  | OIP编码器与解码器分工明确，兼容各类前端后端设备            |
| 简洁布线  | 全系统只需 CAT6 网线，无需 HDMI、USB 延长线等复杂布线      |
| 平台兼容  | 支持 Zoom、Teams、Meet 等标准视频平台，通过 USB-C 直接接入 |
| 灵活部署  | 可适配教室、会议室、培训室、报告厅等场景                   |



## 传统部署对比

| 项目     | 传统会议系统           | Lumens Dante方案           |
| -------- | ---------------------- | -------------------------- |
| 音频连接 | 模拟/数字音频线（XLR） | 网络音频（Dante）          |
| 视频传输 | HDMI/VGA 等物理线缆    | IP视频（Dante AV-H）       |
| 控制接口 | RS232 / GPIO           | IP + API 控制              |
| 可扩展性 | 接口数量限制           | 任意扩展，靠网络交换机即可 |
| 施工布线 | 复杂                   | 一根网线搞定，施工简洁     |
